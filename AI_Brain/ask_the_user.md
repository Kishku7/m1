# Ask the user (shared interaction contract)
<!-- Valid as of: M1 v0.5.0 | MC 1.20 - 26.3 | updated 2026-06-29 -->
**Covers:** when to ask the user a question vs decide yourself, and how to present choices. Used by
`02_create_world.md`, `03_join_multiplayer.md`, and any open-ended task.

**Status:** STUB.

**Planned sections:**
- ASK (don't assume): world name, seed, game mode, difficulty, cheats on/off, which server/address,
  anything destructive or irreversible.
- DECIDE yourself: low-stakes defaults, in-the-moment tactics, recoverable steps.
- HOW to ask: offer a short labelled set of options with a recommended default; one question at a
  time; confirm back what you understood before acting.
